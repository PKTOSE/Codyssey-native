| 빈 제목 문제                                            | 제목을 입력하지 않아도 빈 카드가 추가됨                              | 반영                 | 빈 제목의 영화가 추가되는 것은 기획서 의도와 맞지 않음                                    |
| 휴대폰으로 열어 보니까 좀 불편했어요                    | 브라우저 화면을 줄이면 일부 요소가 잘리는 현상이 발생함              | 반영                 | 화면 크기에 따라 레이아웃이 조정되지 않아 모바일 환경에서 사용하기 불편함                 |
| 카드 옮기는 게 처음엔 좀 헷갈렸어요                     | 카드를 드래그해서 옮기는 방식이지만 별도의 안내가 없음               | 반영                 | 처음 사용하는 사람도 조작 방법을 쉽게 이해할 수 있도록 간단한 안내가 필요함               |
| 카드를 끌어서 옮기는 게 불편했어요                      | 미분류 영화 목록이 아래에 있어 S칸으로 옮기려면 화면을 스크롤해야 함 | 반영                 | 영화 목록을 위나 옆에 배치하면 드래그 이동 거리를 줄여 사용성을 개선할 수 있음            |
| 카드 색이 좀 칙칙한 느낌?                               | 색상에 따른 기능상 문제는 확인되지 않음                              | 보류                 | 색상은 개인 취향에 해당하며 반드시 수정해야 할 문제는 아님                                |
| 영화 포스터 사진이 같이 나오면 훨씬 보기 좋을 것 같아요 | 현재 영화 카드에는 제목만 표시됨                                     | 보류                 | 포스터를 추가하면 시각적으로 좋겠지만 이미지 자료 확보와 관리가 필요하고 필수 기능은 아님 |
| C칸은 굳이 없어도 될 것 같아요                          | C칸에도 영화를 정상적으로 배치할 수 있음                             | 보류                 | 아쉬웠던 영화도 기록하고 비교할 수 있으므로 C티어를 유지하는 것이 좋다고 판단함           |

- 아무도 말하지 않았는데 내가 찾은 것:
    - 화면 크기를 줄이면 일부 영역이 잘리는 문제가 발생함. 반응형 레이아웃이 필요함.

- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유:
    - 드래그 앤 드롭 방식이 직관적이지만, 영화 목록과 티어 사이의 거리가 멀면 사용하기 불편해짐. 기존 화면 구성을 유지하면서 사용성을 개선할 방법을 이야기해 보고 싶음.
