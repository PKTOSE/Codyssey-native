# 영화 티어리스트 웹페이지 기획서

> 버전: v0.2  
> 상태: 기획 단계 (웹페이지 구현 전)  
> 프로젝트 규모: **`index.html` 파일 하나로 완성하는 소규모 개인 프로젝트**

## 1. 한 줄 소개

영화를 S~D 티어에 자유롭게 배치하고, 완성한 목록을 **JSON 파일로 공유**하거나 **친구의 JSON 파일을 불러와 서로의 평가를 비교**할 수 있는 영화 티어리스트 웹페이지.

## 2. 누가, 왜 사용하는가?

- **대상:** 혼자 영화를 정리하거나 친구와 취향을 비교하고 싶은 사람.
- **목적:** 영화에 순위를 매기는 과정 자체를 재미있고 쉽게 만들고, 서로 평가가 다른 영화를 빠르게 찾아보기.
- **사용 방식:** 로그인 없이 페이지를 열어 바로 사용. 친구와의 공유는 파일을 메신저 등으로 직접 주고받는 방식.
- **기본 환경:** PC 화면 우선, 모바일에서도 기본적인 등록·이동·비교 가능.

## 3. 프로젝트 형태와 기본 원칙

1. **모든 화면, 스타일, 동작은 하나의 `index.html` 안에 작성한다.** CSS와 JavaScript도 이 파일 내부에 포함한다.
2. 별도 설치, 빌드, 서버, 데이터베이스, 계정 생성 없이 사용한다. 인터넷 연결이나 외부 영화 정보 서비스도 필요하지 않다.
3. `index.html`을 브라우저에서 직접 열어도 주요 기능이 동작해야 한다.
4. 사용자가 고른 포스터만 사용하며, 별도 이미지 폴더를 요구하지 않는다.
5. 사용자의 작업은 브라우저에 자동 저장하고 JSON 파일로도 보관할 수 있게 한다.
6. 비교 기능은 **실시간 공동 편집이 아니라 각자의 JSON 파일을 읽어 비교**하는 방식으로 구현한다.
7. 원조 TierMaker의 직관적인 티어 보드 배치를 참고하지만 로고나 고유 그래픽을 그대로 복제하지 않는다.

## 4. 화면 구성

### 4.1 메인: 영화 티어리스트

- **상단:** 티어리스트 제목(수정 가능), `영화 추가`, `JSON 저장`, `JSON 불러오기`, `친구와 비교` 버튼.
- **중앙:** 왼쪽에 색상별 S/A/B/C/D 라벨, 오른쪽에 영화 카드를 놓는 가로형 티어 보드.
- **하단:** 아직 티어에 넣지 않은 영화들이 모이는 **미분류 영역**.
- **영화 카드:** 포스터가 있으면 포스터와 제목, 없으면 제목이 읽기 쉬운 텍스트 카드. 개봉 연도를 입력한 경우 함께 표시.
- **조작:** 마우스로 카드를 끌어서 티어 사이 또는 같은 티어 안에서 이동. 카드 클릭 시 수정·삭제 가능. 모바일이나 드래그가 불편한 환경에서는 카드를 누르고 이동할 티어를 선택할 수 있게 한다.

```text
┌──────────────────────────────────────────────────────────┐
│ Movie Tier   [내 영화 티어리스트]                        │
│ [+ 영화 추가] [JSON 저장] [JSON 불러오기] [친구와 비교]   │
├─────┬────────────────────────────────────────────────────┤
│  S  │ [포스터] [포스터]                                   │
├─────┼────────────────────────────────────────────────────┤
│  A  │ [포스터]                                            │
├─────┼────────────────────────────────────────────────────┤
│  B  │ [포스터] [제목 카드]                                 │
├─────┼────────────────────────────────────────────────────┤
│  C  │                                                     │
├─────┼────────────────────────────────────────────────────┤
│  D  │                                                     │
├─────┴────────────────────────────────────────────────────┤
│ 미분류     [포스터] [제목 카드] [포스터]                  │
└──────────────────────────────────────────────────────────┘
```

**기본 티어 색상:** S=빨강, A=주황, B=노랑, C=연두, D=초록. 배경은 어두운 회색. 티어 이름과 색상은 사용자가 바꿀 수 있고, 티어를 추가하거나 삭제할 수도 있다. 삭제된 티어의 영화는 미분류로 이동한다.

### 4.2 영화 추가·수정 창

| 입력 항목 | 필수 여부 | 동작 |
|---|---|---|
| 영화 제목 | **필수** | 직접 입력, 공백만 입력하면 저장 불가 |
| 개봉 연도 | 선택 | 숫자 4자리 입력, 비워도 됨 |
| 포스터 | 선택 | 기기에서 JPG/PNG/WebP 파일 직접 업로드, 미등록 가능 |

- 추가한 영화는 기본적으로 **미분류**에 들어간다.
- 같은 제목과 연도로 등록된 영화가 있으면 중복 가능성을 알려주되 등록을 강제로 막지는 않는다.
- 포스터 이미지는 페이지 내부에서 적당한 크기로 줄여 저장·표시한다.

### 4.3 친구와 비교 화면

- `친구와 비교` → 친구의 JSON 파일 선택 → **내 티어 / 친구 티어**를 나란히 표시.
- 서로 공통으로 평가한 영화는 같은 영화로 인식하여 티어 차이를 확인한다.
- `다르게 평가한 영화만 보기` 필터를 제공한다.
- 영화별 비교 예시: **인터스텔라 — 나: S / 친구: B**.
- **공통 영화 수**, **평가가 다른 영화 수**, **한쪽에만 있는 영화**를 간단히 표시한다.
- 비교 화면을 닫으면 기존 내 리스트로 돌아온다. **친구 파일을 비교하는 것만으로 내 데이터가 바뀌지 않는다.**
- 영화 일치는 기본적으로 `제목 + 개봉 연도`로 판단한다. 한쪽에 연도가 없다면 제목이 유일한 경우에만 같은 영화로 취급하며, 동명 영화 등 애매한 경우는 임의로 합치지 않는다.
- 티어 이름이 서로 다르면 이름을 기준으로 표시하고, 이름만으로 동등한 티어인지 판단할 수 없을 때는 무리하게 수치화하지 않는다.

## 5. 저장과 공유

### 5.1 평소 작업 저장

- 영화 등록, 수정, 티어 이동 등 변경사항은 **브라우저에 자동 저장**한다.
- 새로고침 후에도 작업 내용이 남도록 한다.
- 브라우저 데이터 삭제나 저장 공간 부족에 대비하여 **JSON 저장**을 백업 수단으로 제공한다.

### 5.2 JSON 파일 저장·불러오기

- `JSON 저장`: 현재 리스트의 제목, 영화 정보, 포스터, 티어 구성, 순서를 **`.json` 파일 하나**로 내려받는다.
- `JSON 불러오기`: 기존 JSON 파일을 선택해 해당 리스트를 내 작업 목록으로 불러온다. 현재 데이터를 바꾸기 전 확인 창을 보여준다.
- 포스터는 JSON 안에 이미지 데이터로 포함하여, **친구가 포스터 파일을 따로 받을 필요가 없도록** 한다.
- 포스터 때문에 파일 크기가 커질 수 있으므로, 업로드 이미지는 축소·압축해 저장한다.
- `친구와 비교`는 `JSON 불러오기`와 별개 기능이며 **현재 리스트를 덮어쓰지 않는다**.
- 유효하지 않은 JSON 파일을 열면 오류를 알리고 기존 작업은 유지한다.

**공유 예시:** 내가 만든 리스트 → JSON 파일 저장 → 카카오톡 등으로 친구에게 전달 → 친구가 자신의 페이지에서 불러오거나 비교.

### 5.3 JSON 예시 (구조 참고용)

아래는 **포스터를 생략한 예시**이며, 실제 저장 파일에는 업로드한 포스터 데이터도 포함한다.

```json
{
  "version": 1,
  "title": "내 영화 티어리스트",
  "tiers": [
    { "id": "s", "name": "S", "color": "#ff7f7f", "movieIds": ["m1"] },
    { "id": "a", "name": "A", "color": "#ffbf7f", "movieIds": [] },
    { "id": "b", "name": "B", "color": "#ffdf7f", "movieIds": [] },
    { "id": "c", "name": "C", "color": "#bfff7f", "movieIds": [] },
    { "id": "d", "name": "D", "color": "#8fdf9f", "movieIds": [] }
  ],
  "movies": [
    { "id": "m1", "title": "인터스텔라", "year": 2014, "poster": null },
    { "id": "m2", "title": "기생충", "year": null, "poster": null }
  ],
  "unrankedMovieIds": ["m2"]
}
```

## 6. 이번 프로젝트에 포함할 기능

| 구분 | 기능 | 범위 |
|---|---|---|
| 영화 관리 | 제목·연도·포스터 등록, 수정, 삭제 | 필수 |
| 티어 보드 | S~D 배치, 드래그 이동, 티어 안 순서 변경, 미분류 | 필수 |
| 티어 설정 | 이름·색상 변경, 티어 추가·삭제 | 포함 |
| 저장 | 브라우저 자동 저장 | 필수 |
| 파일 공유 | 포스터 포함 JSON 저장·불러오기 | 필수 |
| 친구 비교 | JSON 선택, 나란히 보기, 서로 다른 영화 필터 | 필수 |
| 모바일 | 카드 선택 후 티어 지정 | 포함 |
| 편의 기능 | 영화 제목 검색, 중복 입력 경고 | 있으면 좋음 |

**이번에는 만들지 않는 기능:** 회원가입, 서버 저장, URL로 공유, 영화 자동 검색, 포스터 자동 검색, 실시간 공동 편집, 여러 명 동시 비교, 통계 대시보드, 영화 추천 AI.

## 7. 완성 기준

- [ ] **`index.html` 파일 하나만으로** 웹페이지가 실행된다. 별도 파일·설치·외부 라이브러리를 요구하지 않는다.
- [ ] 영화 제목만 입력해도 카드를 만들 수 있다.
- [ ] 선택적으로 개봉 연도와 포스터 이미지를 추가할 수 있다.
- [ ] 영화 카드를 S~D 티어로 이동하고 다시 미분류로 돌릴 수 있다.
- [ ] 티어 설정을 바꾸거나 영화를 편집해도 기존 배치가 유지된다.
- [ ] 새로고침 후에도 브라우저에 저장된 작업이 복원된다.
- [ ] JSON으로 내보낸 파일을 다른 브라우저에서 불러오면 제목·연도·포스터·티어 배치가 복원된다.
- [ ] 친구 JSON과 나란히 비교하고 서로 다른 영화만 볼 수 있다.
- [ ] 친구 비교를 종료해도 내 티어리스트는 변경되지 않는다.
- [ ] 잘못된 JSON 파일을 열어도 기존 데이터가 손상되지 않는다.

## 8. 구현 전에 확정한 기본 선택

- **파일:** `index.html` 하나만 사용.
- **기본 티어:** S, A, B, C, D (변경 가능).
- **포스터:** 직접 업로드만 지원 (선택 사항).
- **친구 비교:** 1:1 비교, JSON 파일 방식.
- **화면 분위기:** TierMaker처럼 가로로 길게 나열되는 어두운 티어 보드.
- **우선순위:** 기능이 확실하게 작동하는 가볍고 단순한 웹페이지. 복잡한 설정이나 꾸미기는 최소화.

> **현재는 기획서만 작성한다. 실제 HTML 코드는 아직 만들지 않는다.**
