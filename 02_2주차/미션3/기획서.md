# MemoFlip — 일본어 단어 암기장·퀴즈

## 대상 사용자

- 기초 일본어 단어·표현을 반복 암기하려는 일본어 입문 학습자 및 학생
- 주 사용자는 본인이며, 내보낸 JSON 파일을 친구와 교환해 같은 일본어 단어 목록을 학습할 수도 있다.

## 사용 목적

- 일본어 단어·표현과 한국어 뜻을 카드로 정리하고, 플래시카드로 반복 학습한다.
- 퀴즈에서 일본어 단어를 보고 한국어 뜻을 떠올린 후 정답을 확인하고, 맞음/틀림을 직접 판단하여 학습 결과를 확인한다.
- 별도의 로그인이나 서버 없이 개인 브라우저에 단어 목록을 보관하고, JSON 파일로 백업·복원한다.

## 화면 구성과 동작

1. **단어 관리 화면**: 등록된 일본어 단어/표현과 한국어 뜻의 목록, 새 단어 등록 입력창, 항목별 수정·삭제 버튼을 보여 준다. 일본어와 한국어 뜻을 입력하고 `단어 등록`을 누르면 목록에 새 카드가 생긴다. 수정·삭제한 내용은 즉시 반영된다.
2. **플래시카드 학습 화면**: 한 번에 카드 한 장을 표시한다. 처음에는 일본어 단어를 보여 주고, 카드를 누르거나 `정답 보기`를 누르면 한국어 뜻으로 전환한다. `이전`·`다음` 버튼으로 카드를 이동한다.
3. **퀴즈 화면**: 일본어 단어를 한 장씩 제시한다. 학습자가 스스로 한국어 뜻을 떠올린 후 정답을 확인하고 `맞음` 또는 `틀림`을 누르면 해당 판단을 기록한 후 다음 문제로 진행한다. 모든 문제를 마치면 맞힌 수, 틀린 수, 정답률을 보여 준다. **문자열 비교나 AI 자동 채점은 하지 않는다.**
4. **데이터 관리 영역**: 변경된 카드 데이터를 브라우저에 자동 저장한다. `JSON 내보내기`를 누르면 카드 데이터 파일을 다운로드한다. `JSON 가져오기`로 올바른 파일을 선택하면 **기존 카드 전체를 대체한다는 확인창**을 먼저 띄우고, 사용자가 승인한 경우에만 대체한다. 취소하면 기존 카드가 그대로 남는다.
5. **시작 상태**: 처음 실행해 저장된 카드가 없을 때는 HTML에 내장된 기초 일본어 단어·표현 20개를 보여 준다. 이후에는 브라우저에 저장된 사용자의 카드 목록을 불러온다.

### 필수 기능 (첫 번째 버전)

- 일본어 단어·표현과 한국어 뜻으로 구성된 카드 등록, 목록 열람, 수정, 삭제
- 빈 일본어 단어 또는 빈 한국어 뜻 입력 방지
- 플래시카드 앞면(일본어)·뒷면(한국어 뜻) 전환 및 이전·다음 탐색
- 사용자가 정답 확인 후 직접 `맞음`·`틀림`을 선택하는 퀴즈와 최종 결과(정답 수, 오답 수, 정답률)
- 브라우저 로컬 저장소를 이용한 자동 저장 및 재접속 시 복원
- JSON 내보내기 및 가져오기(가져오기 시 대체 확인, 취소 시 원본 유지)
- `기본 20개로 초기화` 버튼으로 추가·수정한 내용을 지우고 내장된 일본어 단어 20개로 복구(확인창 표시)
- 외부 라이브러리·로그인·서버 없이 단일 HTML 파일 실행

### 추가 기능 (이후 구현할 기능)

- **주제별 단어 묶음**: 인사, 사람, 음식, 시간 등 일본어 어휘 주제를 지정하고 특정 묶음만 선택하여 학습
- **랜덤 카드 학습**: 플래시카드 또는 퀴즈의 카드 출제 순서를 무작위로 섞기
- **오답 재학습**: 마지막 퀴즈에서 `틀림`으로 선택한 카드만 모아 다시 학습

- 첫 실행에 표시할 **기초 일본어 단어·표현 20개**(별도 파일 없이 HTML 안에 내장):

- 카드의 기본 데이터 항목: 고유 ID, 일본어 단어·표현(문제), 한국어 뜻(정답). 한자 단어는 괄호 안에 읽는 법을 함께 표기한다.
- JSON 백업 파일: `format` 값과 `words` 배열을 포함하며, 단어마다 `id`, `question`, `answer` 항목을 가진다. 올바르지 않은 형식은 가져오지 않는다.

## 완료 기준

1. 일본어 단어와 한국어 뜻을 입력하고 `단어 등록`을 누르면 카드 목록에 새 카드가 정확히 1개 추가된다.
2. 일본어 단어 또는 한국어 뜻을 비운 채 `단어 등록`을 누르면 카드가 추가되지 않고 입력 안내 메시지가 표시된다.
3. 일본어 단어 또는 한국어 뜻을 수정하여 저장하면 카드 목록과 학습 화면에 수정된 내용이 표시된다.
4. 카드를 삭제하면 목록 및 이후의 학습 대상에서 사라진다.
5. 플래시카드에서 카드를 누르거나 `정답 보기`를 누르면 해당 단어의 한국어 뜻이 나타난다.
6. `이전`·`다음` 버튼을 누르면 표시되는 카드가 순서에 맞게 바뀐다(첫 카드와 마지막 카드에서 범위를 벗어나지 않는다).
7. 퀴즈에서 정답 확인 뒤 `맞음` 또는 `틀림`을 누르면 응답이 기록되고 다음 문제로 이동한다.
8. 퀴즈의 모든 문제를 처리하면 맞힌 개수, 틀린 개수, 정답률이 표시된다. 예를 들어 20문제 중 15개를 `맞음`으로 선택하면 **정답 15개·오답 5개·정답률 75%**가 표시된다.
9. 카드를 3개 추가한 뒤 페이지를 새로고침하거나 동일 브라우저에서 같은 HTML을 다시 열면 추가된 카드 3개와 기존 카드가 유지된다(브라우저가 로컬 저장을 허용하는 환경 기준).
10. `JSON 내보내기`를 누르면 현재 카드 목록을 담은 JSON 파일이 다운로드된다.
11. 내보낸 JSON 파일을 가져와 대체를 승인하면 파일에 포함된 카드가 복원된다. 대체 확인을 취소하면 기존 카드 목록은 바뀌지 않는다.
12. 저장된 카드가 없는 상태에서 처음 열면 내장된 일본어 단어·표현 **20개**가 보인다.
13. HTML 파일을 더블클릭하여 열면 로그인, 인터넷 연결, 별도의 서버 및 다른 파일 없이 기본 기능을 사용할 수 있다.
14. `기본 20개로 초기화`에서 확인을 누르면 기본 일본어 단어 20개로 복구되고, 취소하면 현재 목록이 유지된다.
15. 좁은 모바일 화면에서도 주요 입력창과 버튼이 화면 밖으로 잘려 조작할 수 없는 상태가 되지 않는다.

## 한계 및 비목표

1. **자동 채점 제외**: 단답형 텍스트를 자동 비교하거나 AI로 답을 판정하지 않는다. 사용자가 직접 `맞음`·`틀림`을 결정한다.
2. **온라인 계정·동기화 제외**: 로그인, 서버 저장, 기기 간 실시간 동기화 및 공동 편집을 지원하지 않는다. 브라우저 저장 자료는 환경에 따라 지워질 수 있으므로 JSON 파일로 백업한다.
3. **첫 버전의 학습 범위 제한**: 기초 일본어 단어·표현 20개를 기본 제공하며, 첫 버전에서는 등록된 모든 카드를 순서대로 학습한다. 주제별 묶음, 랜덤 출제, 오답 재학습은 후속 구현 대상으로 둔다.

## 검증 방법

- **비교 대상**: 위 표의 기본 일본어 단어 20개·한국어 뜻 원본과 직접 계산한 퀴즈 결과.
- **절차**: (1) 최초 실행 시 단어가 20개인지 확인하고, `こんにちは → 안녕하세요`, `学校（がっこう） → 학교`, `食べる（たべる） → 먹다`를 포함해 위 표의 20쌍과 화면을 대조한다. (2) 퀴즈 20문제 중 15개를 `맞음`, 5개를 `틀림`으로 선택한다. (3) 화면에 표시된 정답 수 15, 오답 수 5, 정답률 75%를 수작업 계산값 `15 ÷ 20 × 100 = 75%`와 비교한다. (4) JSON을 내보냈다가 가져온 후 단어 개수와 일본어·한국어 뜻이 내보내기 전 목록과 일치하는지 대조한다.

- AI 서비스: **ChatGPT (OpenAI)**
- 모델: **GPT-6**
