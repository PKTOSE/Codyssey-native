## 수정 기록

### 수정 기록 1 — 셀프 퀴즈의 중복된 정답 확인 버튼 제거

- **발견한 문제 (관찰·예상·실제):** 셀프 퀴즈에서 **카드를 클릭하면 정답이 표시되는데**, 카드 아래에 `정답 확인` 버튼도 따로 있었다. 정답 확인 수단이 중복되어 학습 중 불필요한 이동과 선택이 생겼다. 예상한 사용 흐름은 *카드 클릭 → 뜻 확인 → 맞음/틀림 판단*이었지만, 실제 화면에는 추가 버튼이 있었다.
- **AI에게 전달한 요청:** “이거 셀프 퀴즈에서 정답 확인 버튼을 없애줘. 차피 카드 클릭하면 정답으로 보이잖아.”
- **수정 후 테스트 결과:** HTML에서 퀴즈 전용 `정답 확인` 버튼과 해당 버튼에 연결된 처리가 제거된 것을 코드 비교로 확인했다. 카드 클릭으로 정답을 확인하는 기능과 `맞음`·`틀림` 버튼은 유지되어 있다. **실제 브라우저에서의 최종 재확인 여부는 별도로 기록 필요.**
- **수정 이유:** 동일한 기능을 하는 버튼을 줄여 조작 과정을 간소화하고, 정답 확인에서 채점으로 이어지는 흐름을 명확하게 하기 위해서다.
- **버전:** `MemoFlip_일본어_단어장.html` → `MemoFlip_일본어_단어장_정답버튼삭제.html`

### 수정 기록 2 — 퀴즈 카드와 맞음·틀림 버튼 사이 간격 조정

- **발견한 문제 (관찰·예상·실제):** 수정 기록 1 이후 셀프 퀴즈의 카드와 `✓ 맞음`·`✕ 틀림` 버튼이 시각적으로 너무 붙어 있었다. 예상한 화면은 카드와 채점 영역이 구분되는 배치였으나, 실제 화면에서는 간격이 부족하게 느껴졌다.
- **AI에게 전달한 요청:** “이번엔 플래시 카드랑 맞음 틀림 버튼이 너무 붙어있어. 조금만 띄워줘.”
- **수정 후 테스트 결과:** 변경 전후 HTML의 CSS를 비교한 결과, `.quiz-response`에 `margin-top: 24px`이 추가되었다. 다른 기능의 JavaScript는 변경되지 않았다. **여러 화면 크기에서 충분한 간격인지 시각적 재확인 필요.**
- **수정 이유:** 문제 영역과 자기 채점 버튼을 시각적으로 분리해 가독성과 조작 편의성을 개선하기 위해서다.
- **버전:** `MemoFlip_일본어_단어장_정답버튼삭제.html` → `MemoFlip_일본어_단어장_버튼간격수정.html`

### 수정 기록 3 — 단어 중복 추가 오류 해결

- **발견한 문제:** 이미 등록된 일본어 단어를 다시 추가해도 중복 확인 없이 목록에 등록되는 문제가 있었다.
- **AI에게 전달한 요청:** 이미 단어 목록에 있는 일본어 단어는 중복으로 등록되지 않도록 수정해 줘. 기존 기능은 유지해 줘.
- **수정 후 테스트 결과:** 중복 등록을 차단하는 코드를 추가하고 JavaScript 문법 검사를 통과했다. 실제 브라우저에서 중복 등록 및 수정 동작을 재테스트해야 한다.
- **수정 이유:** 동일한 단어의 여러 뜻을 별도로 관리하는 기능이 아니라, 의도치 않게 같은 단어가 여러 번 등록되는 문제이므로 이를 방지해 단어 목록을 효율적으로 관리하고자 했다.

## 사용자 테스트

- **테스트 참여자와 요청한 작업:** 일본어를 공부하는 친구 1명에게 별도의 사용 설명 없이 MemoFlip을 사용하도록 요청하였다. 새 단어 등록, 플래시카드 학습, 셀프 퀴즈 3문제 진행, 단어 수정, JSON 백업을 수행하도록 하였다.

- **사용자의 행동과 질문:**
    - 단어 등록과 플래시카드 학습, 셀프 퀴즈, 단어 수정 및 JSON 백업 기능을 사용하도록 요청하였다.
    - JSON 파일을 내보내는 과정에서 파일명에 날짜가 자동으로 포함되면 좋겠다는 의견을 제시하였다.

- **받은 피드백:** JSON 파일을 여러 번 백업할 경우 파일명만으로 저장 시점을 구분하기 어려우므로, 기본 파일명 뒤에 현재 날짜를 자동으로 추가해 달라는 피드백을 받았다.

- **반영 내용과 결과:** JSON 내보내기 기능을 수정하여 `memoflip-japanese-words-YYYY-MM-DD.json` 형식으로 저장되도록 변경하였다. 기존 JSON 데이터 구조와 가져오기 기능은 유지하였으며, JavaScript 문법 검사를 통과하였다. 실제 브라우저에서 다운로드 파일명과 복원 동작을 최종 확인할 예정이다.
